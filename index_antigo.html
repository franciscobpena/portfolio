Credit Scoring para Empréstimos Pessoais

Neste projeto, utilizei técnicas de modelagem estatística para desenvolver um modelo de credit scoring para avaliação de solicitantes de empréstimos pessoais. O resultado final do projeto foi um modelo de regressão logística capaz de prever o risco de crédito de novos solicitantes com base em seu histórico financeiro. O modelo pode ser integrado aos sistemas de avaliação de crédito de instituições financeiras para auxiliar na tomada de decisões sobre concessão de empréstimos.

Análise Exploratória de Dados (EDA) do Mercado de Aluguel de Imóveis no Brasil

Neste projeto, realizamos uma Análise Exploratória de Dados (EDA) para entender o mercado de aluguel de imóveis no Brasil. O foco foi identificar padrões de preços, tamanhos de propriedades, número de vagas de garagem, e fatores como localização e proximidade a estabelecimentos comerciais.
